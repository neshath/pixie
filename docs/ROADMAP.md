# Pixie roadmap

## 0.1 — current foundation

- Square Godot workstation shell.
- GFX pixel grid with palette, frames, onion skin, and tools.
- MAP tile/collision grid.
- RUN movement, collision, NPC, dialogue.
- Human-readable project JSON.
- Safe local MCP tool server.
- Simple / Advanced disclosure.

## 0.2 — authoring depth

- Sprite-sheet import/export.
- Aseprite-compatible metadata import where licensing permits.
- Tile stamps and terrain brushes.
- Layer compositing and per-layer opacity.
- Directional animation sets and preview timeline.
- Dialogue choices, variables, and scene hooks.
- Dedicated audio desks.

## 0.3 — agent workflows

- MCP transaction previews and undo.
- Agent-generated patch plans with user approval.
- Scene screenshot/context tool.
- Provider profiles that never store secrets in project files.
- Test/play loop exposed as MCP tools.

## 0.4 — shipping

- Standalone game export.
- Linux/Windows/macOS packaging.
- Accessibility and keyboard audit.
- Plugin SDK with explicit capability grants.
- GPU lighting, particles, and shader graph authoring.

The current build is a foundation, not a claim that every item above is already finished.
